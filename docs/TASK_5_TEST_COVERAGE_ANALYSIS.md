**原因**: 使用了错误的测试库导入

**错误详情**:
```

```

```typescript
import { render } from 'solid-js/web';
```

**影响**: 不影响核心功能
- 基础 ErrorBoundary 组件已完全测试通过
- ChatErrorBoundary 可使用相同模式重写
