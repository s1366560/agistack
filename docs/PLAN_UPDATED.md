## 1. 项目概述

### 1.1 目标

构建一个**完全可本地部署**的基于 Web 的 AI 编程助手应用，提供类似 OpenCode 的核心功能：

- **多 AI 提供商支持**：Anthropic、OpenAI、Google、Groq 等
- **多 Agent 系统**：构建、规划、通用 Agent
- **代码操作**：文件读写、编辑、搜索、导航
- **会话管理**：多会话、历史记录、分享
- **LSP 集成**：代码智能提示
- **MCP 支持**：扩展插件系统
- **终端集成**：命令执行
- **实时同步**：WebSocket 支持

### 1.2 本地部署特性

✅ **无云依赖**：所有组件可在本地运行
✅ **自包含**：单一可执行文件或 Docker 镜像
✅ **数据隐私**：所有数据存储在本地
✅ **离线可用**：支持离线模式（本地 LLM）
✅ **易于部署**：一行命令启动

### 1.3 核心特性

| 特性 | 描述 | 优先级 | 状态 |
|------|------|--------|------|
| 多模型支持 | 支持多家 AI 提供商 | P0 | 🚧 60% |
| 文件操作 | 读取、编辑、搜索代码 | P0 | ✅ 80% |
| 会话管理 | 多会话、历史记录 | P0 | ✅ 90% |
| 本地存储 | PostgreSQL 本地数据库 | P0 | ✅ 80% |
| WebSocket 通信 | 实时消息推送 | P0 | ❌ 0% |
| 权限系统 | 细粒度访问控制 | P1 | 🚧 50% |
| LSP 集成 | 代码智能 | P1 | ❌ 0% |
| 终端集成 | 命令执行 | P2 | 🚧 40% |
| MCP 支持 | 插件系统 | P2 | ❌ 0% |

## 2. 技术栈选型（本地部署版）

### 2.1 前端技术栈

#### 核心框架
- ✅ **SolidJS 1.9+** - 响应式 UI 框架
  - 原因：高性能、细粒度响应式、类似 React 语法
  - 状态: ✅ 完成

- ✅ **Vite 7+** - 构建工具
  - 快速热更新
  - 优秀的开发体验
  - 状态: ✅ 完成

#### UI 组件
- ✅ **TailwindCSS 4+** - 样式框架
  - 状态: ✅ 完成
- ❌ **@kobalte/core** - 无障碍 UI 原语 (未使用)
- 🚧 **自定义组件库** - 复用 OpenCode 设计 (进行中)

#### 状态管理
- ✅ **SolidJS Context** - 全局状态
  - 状态: 🚧 进行中
- ✅ **CreateSignal** - 局部状态
  - 状态: ✅ 完成
- ❌ **SolidStore** - 复杂状态管理 (未使用)

#### 路由
- ✅ **@solidjs/router** - 文件路由
  - 状态: ✅ 完成
- ✅ **@solidjs/start** - SSR 框架
  - 状态: ✅ 完成

### 2.2 后端技术栈（本地部署）

#### 运行时
- ✅ **Bun 1.3+** - JavaScript 运行时
  - 原因：极速、原生 TypeScript、内置包管理器
  - 可打包为单一可执行文件
  - 状态: ✅ 完成

#### Web 框架
- ✅ **Hono 4+** - 轻量级 Web 框架
  - 支持 Bun 原生运行
  - 类似 Express API，易于上手
  - 内置 WebSocket 支持
  - 状态: ✅ 90% 完成

#### HTTP 服务器
- ✅ **Bun.serve** - 内置 HTTP 服务器
  - 无需 Nginx/Apache
  - 极高性能
  - 自动 HTTPS（可选）
  - 状态: ✅ 完成

#### AI 集成
- 🚧 **Vercel AI SDK 5+** - LLM 抽象层
  - 支持多家提供商
  - 流式响应
  - 工具调用
  - 状态: 🚧 60% 完成
- ❌ **Ollama SDK** - 本地 LLM 支持
  - 支持 Llama、Mistral 等本地模型
  - 状态: ❌ 未开始

#### 数据库
- ✅ **PostgreSQL 15+**（当前使用）
  - 适合大型部署
  - 更强大的并发能力
  - 可使用 Docker 部署
  - 状态: ✅ 80% 完成
- ❌ **SQLite 3**（可选）
  - 零配置
  - 单文件存储
  - 适合个人/小团队
  - 状态: ❌ 未实现

#### ORM
- ✅ **Drizzle ORM** - 类型安全 ORM
  - 支持 SQLite 和 PostgreSQL
  - 零迁移文件
  - 优秀的 TypeScript 支持
  - 状态: ✅ 85% 完成

#### 缓存
- ✅ **Redis 7+**（可选）- 内存缓存
  - 用于会话存储
  - 用于限流计数
  - 可使用 Docker 部署
  - 状态: ✅ 40% 完成 (Docker配置完成，集成未完成)
- ❌ **内存缓存**（默认）- 简单场景
  - 状态: ❌ 未实现

#### 文件存储
- ✅ **本地文件系统** - 默认选项
  - 项目文件直接访问
  - 上传文件存储在本地
  - 无需对象存储
  - 状态: ✅ 80% 完成

#### WebSocket
- ❌ **Bun WebSocket** - 内置支持
  - 实时消息推送
  - 文件变更通知
  - 终端输出流
  - 状态: ❌ 未开始

#### 终端
- 🚧 **node-pty** - PTY 伪终端
  - 完整终端模拟
  - 支持 Shell 命令
  - 跨平台支持
  - 状态: 🚧 40% 完成 (基础工具完成，UI未实现)
